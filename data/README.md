# Данные «Желейного легиона»

Все числа баланса и все уровни живут здесь (ARCHITECTURE, инвариант 4). Стартовые числа — из прототипа (`docs/research/prototype.html`) и GDD (Claude Doc «Желейный легион: GDD», 09.10.2026). После любой правки — `npm run data`.

Формат таблиц: UTF-8 без BOM, запятая, текст с запятой — в кавычках, пустая ячейка — «нет значения». Названия и подсказки — ключи строк из `translations/strings.csv`.

## Единицы и формулы

- Длины — в клетках, время — в секундах, скорость — клеток в секунду. Клетка `(c, r)`: столбец слева направо, ряд сверху вниз; точка `(x, y)`, `y` растёт вниз.
- **Скорость отрыва прыжка** = √(2 × `gravity` × `jump_height`) = √(2 × 30 × 2,5) ≈ 12,25 клетки/с. С шагом 1/60 с короткое нажатие (1 шаг) даёт высоту 2,48 клетки и длину 3,7, полное удержание (`gravity_hold` в течение `hold_max_s`) — 3,45 и 4,5 (замер ядра, совпадает с прототипом; GDD «Желейка и физика»).
- **Лазер** горит, пока `(время уровня + сдвиг) mod laser_period_s < laser_on_s`; пунктир — когда до конца цикла меньше `laser_warn_s`. Сдвиг: `L` — 0, `l` — `laser_alt_phase_s`. Время уровня идёт с первого нажатия.
- **Звёзды**: 3 — легион ≤ пар; 2 — легион ≤ пар + `stars_2_extra`; 1 — уровень пройден.

## Уровни — `levels/<набор>.txt`

```
# комментарий (только вне карты)
level p-02          ← id: a–z, 0–9 и дефисы, уникальный во всех файлах
par 1               ← пар: наименьшее число гибелей — число бота с запасом (npm run solve)
map                 ← дальше ровно grid_rows строк по grid_cols знаков
.............#..........
…
.@..........LD.......F..
############.###########
############P###########
########################
end
```

Знаки карты: `#` земля, `.` воздух, `@` старт (ровно один, под ним земля или плита), `F` флаг (ровно один), `^` шипы, `S` пила, `L` лазер (горит с начала), `l` лазер (со сдвигом на полцикла), `P` плита (твёрдая клетка пола с кнопкой), `D` дверь (есть дверь — есть и плита, и наоборот). Внутри карты строка, начинающаяся с `#`, — это ряд земли, а не комментарий. Позже появится строка `limit N` — лимит легиона (мир 4).

Название и подсказка уровня — строки `level.<id>.name` и `level.<id>.hint`. Порядок уровней в мире — порядок в файле.

## Решения бота — `solutions/<набор>.json`

Пишет `npm run solve` (M0-04, с M0-05 — решения бота с запасом), руками не править. По id уровня: `map` — отпечаток карты, `par` — пар бота с запасом, `strict` — строгий пар (без запаса, не больше `par`), `steps` — время решения в шагах (60 в секунду), `windows` — запас каждого нажатия в своей жизни, шагов (не меньше `par_window_s` × 60), `taps` — нажатия `[шаг, сколько держать]`, шаги считаются от первого нажатия (старт первой желейки). Тест `tests/unit/solutions.test.ts` повторяет решения ядром и проверяет запас. Правка карты, правил или бота → `npm run solve` → `par` в файле уровня равен числу бота.
