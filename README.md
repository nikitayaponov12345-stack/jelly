# Желейный легион

Браузерный раннер на одну кнопку: желейка бежит сама, игрок только прыгает, а каждая погибшая желейка застывает там, где погибла, и становится частью уровня — заполняет яму, держит плиту, перекрывает лазер, служит ступенькой. Первый выпуск — 4 мира по 15 уровней.

Стек: TypeScript, PixiJS 8, Vite, Vitest, Playwright. Площадки первого выпуска: песочница Playgama → CrazyGames → Яндекс Игры (одна сборка, Playgama Bridge); Poki — отдельной сборкой без покупок.

## Команды
- `npm install` — один раз после клонирования (нужны Node.js 22.12+ и npm 11+), затем `npx playwright install chromium`.
- `npm run dev` — игра в браузере с перезагрузкой при правках.
- `npm run check` — проверка данных, тесты, сборка с отчётом о размере и смоук в двух раскладках.
- `npm run solve` — бот-решатель: пар (по боту с запасом) и решение каждого уровня, около минуты.
- `npm run publish` — опубликовать сборку для телефона: https://nikitayaponov12345-stack.github.io/jelly-play/
