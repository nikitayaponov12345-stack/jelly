# Задачи

Как запускать: в PowerShell `cd C:\games\jelly`, затем `claude`; в Claude Code — «Выполни задачу docs/tasks/<файл>.md. Перед началом прочитай CLAUDE.md.» Каждая задача — в новом сеансе Claude Code.

После задачи Claude Code ставит в строке статуса «сделано ДД.ММ» и пишет отчёт. Приёмку по коду делает Claude в чате проекта «игры», коммит и push — Никита.

Порядок пачки 1: S0-01 → M0-01 → M0-02 (каждая следующая опирается на предыдущую; следующую запускать, когда в строке предыдущей стоит «сделано»).

|---|---|---|

| M0-01 | Ядро уровня: разбор уровней, желейка, гибель и застывание, плиты и двери, легион, звёзды; сверка с прототипом | поставлена 09.10 |
| M0-02 | Вид уровня и ввод одной кнопкой: поле и элементы, желейка со сквошем, тела, частицы; камера и карта уровня в портрете; кнопка «Заново», переход по уровням | поставлена 09.10 |
