# M1-05 — проба 2: шесть головоломок с ложным ходом

**Цель.** Проба 0.0.9 (11.11): уровни `?set=pz` — понятные, решение видно сразу, трудность — только вовремя нажать; Никита: «это больше подходит для вводных уровней». Эта задача добавляет вторую пробу — набор `pz2`: шесть уровней, построенных по методу «ИИ придумывает — бот судит» (GDD, «Как строим уровни»). В каждом есть ложный ход, который выглядит верным, и чтобы найти решение, надо подумать, что сделает тело со следующими желейками: плита того же цвета, что мост, обрушит мост; знакомая пила над плитой запрёт коридор; дверь нужна закрытой — как опора; тело на шипах — стена, у которой остановится следующая. Нажатия — с запасом: в решениях бота окно 0,1–0,2 с, а дрожь на уровнях 1 и 6 прощает больше — на шестом годятся две высоты тела. Мир 1 и первая проба не меняются.

**Что изменится в игре.** По адресу игры с `?set=pz2` — шесть уровней: «Мост из двери», «Тесный коридор», «Опора», «Остановка», «Полка», «Три шага», с названиями и подсказками на русском и английском. Без `?set` игра, как и прежде, идёт по миру 1. Версия 0.0.10.

Перед началом прочитай `CLAUDE.md`, `data/README.md` (уровни, миры, решения бота) и в `docs/GDD.md` раздел «Уровни и миры» — правила «Как строим уровни» и таблицу «Головоломки — проба 2».

**Проверка до передачи.** Уровни построены Claude 11.11 и разобраны `npm run analyze` (M1-04) в песочнице: пар в файле — число бота с запасом, строгий бот находит те же числа; решение с паром одно (в «Трёх шагах» — два, они различаются только высотой третьего тела); «простой игрок» пара не берёт ни на одном уровне, а на трёх не доходит вовсе; в каждой жизни — не больше трёх прыжков, и с четырьмя прыжками пар тот же. Ложные ходы проверены: тело на плите под пилой в «Тесном коридоре» запирает уровень (дальше не пройти — только «Заново»), в «Мосте из двери» тело на плите стоит ещё трёх гибелей. Код и уровни прогнаны в песочнице поверх M1-04: `npm run solve` — около 4 минут, вывод — как в §4; `npm run test` — 23 файла, 152 теста; `npm run check` зелёный, Playwright — 15 passed, 1 skipped. Из 4 намеренных поломок (пар в файле уровня, карта уровня без нового `npm run solve`, нет строки подсказки, файл набора не подключён) ловят все: `npm run test` — три, нет строки подсказки — `npm run data` (он идёт первым в `npm run check`).

**Условие.** M1-04 сделана (в `docs/tasks/README.md` у M1-04 стоит «сделано …»). Если нет — остановись и напиши об этом в отчёте.
